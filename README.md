# Tech Notes

A quick reference for keeping track of the frameworks and tools out there.

## What a note contains

Each technology gets its own Markdown file answering four simple questions:

- **The problem**: why was this technology created?
- **The idea**: in one image and a few sentences, how it addresses that need.
- **The use case**: when to reach for it (and when not to).
- **Usage**: a minimal example to get started with it.

## Organization

Notes are grouped by category (back-end, front-end, build-tools, databases, devops, etc.) in dedicated folders. Each note is self-contained: it should be readable on its own, without needing context from the others.
